# Brand asset

engineering-thinking-hackathon.png is the original Engineering Thinking Hackathon wordmark extracted from page 1 of the user-supplied EngineeringThinkingHackathon2026.pdf. The PDF contains flattened page images rather than separate vector logo objects. This asset preserves the navy background, white lettering and blue-to-gold symbol; it is not an AI recreation. Extracted by rendering the logo's PDF region at 144 dpi.

The app palette follows the supplied cover: deep navy, bright blue, warm gold and off-white. S.O.L.V.E OS is a separate text lockup beside the original event artwork.

Home-screen icons (icon-192.png, icon-512.png, apple-touch-icon.png) use a square, navy-background adaptation of the user-provided blue/white/gold crossover symbol. The square source was prepared using image generation and rendered at platform-specific sizes. No text or rounded-corner mask is baked into the icons; the device supplies its home-screen mask.
